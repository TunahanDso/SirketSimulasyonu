# Uc Kardes Yazilim Sirketi Simulasyonu

## Projeler

- Motor: C# / .NET 8
- Tunahan: Rust
- Mustafa: Go
- Ugur: Node.js

## Ilk hedef

Motorun LAN uzerinden uc sirket sunucusuna baglanmasi,
sirketlerin kimliklerini almasi ve saglik kontrolu yapmasi.
